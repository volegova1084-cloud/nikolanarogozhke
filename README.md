# Никольский храм — три концепции главной

Предварительный этап Spec First, 2026-10-08. Рабочая ветка: `design/homepage-concepts`. Главная и внутренние страницы не утверждены. GitHub Pages не опубликованы.

## Посмотреть

Скачайте рабочую ветку целиком (GitHub → выберите ветку → Code → Download ZIP), распакуйте и откройте `concepts/index.html`. Сборка и npm не нужны. CSS, шрифты и знак локальные. Не скачивайте один HTML без папок ресурсов.

При необходимости локального HTTP-сервера из корня проекта:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/concepts/index.html`.

| Файл | Концепция |
|---|---|
| `concepts/index.html` | Галерея реальных превью и переключаемый адаптивный предпросмотр |
| `concepts/concept-01.html` | Архитектурная элегантность: арка, равные колонки новостей |
| `concepts/concept-02.html` | Современное православное наследие: геометричная рама, иерархичная лента, зелёный блок истории |
| `concepts/concept-03.html` | Свет и гармония: округлые окна, открытая лента, воздушная композиция |

Все страницы содержат двухуровневую шапку, hero, новости, о храме, святыни, приходскую жизнь, контакты/карту, подвал. Bootstrap 5.3.3 (MIT), Golos Text и Cormorant Garamond (SIL OFL 1.1). Все пути относительные.

## Ограничения материалов

Фото реального храма и икон не перепубликованы: разрешение не подтверждено. Вместо них — подписанные места под оригиналы. Новости и приходские материалы демонстрационные. Точный адрес, телефон, часы работы ожидают подтверждения. Яндекс Карта подписана как заглушка, без ложного маркера. Кнопки будущих разделов показывают dialog статуса, а не отправляют записки или открывают несуществующие страницы.

Источники и лицензии — `specs/assets.md`, исследования — `specs/reference-analysis.md`, результаты QA — `specs/progress.md`.

## GitHub Pages — только после утверждения

Никаких настроек публикации на этом этапе не меняли. После прямого разрешения можно выбрать отдельную ветку публикации и публиковать её корень через Settings → Pages; URL галереи будет иметь путь `/nikolanarogozhke/concepts/`. Перед публикацией проверить, что выбранная ветка содержит утверждённые материалы. Не назначать рабочую ветку источником Pages автоматически. Не выполнять merge в main до согласования.

## Выбранная концепция 01 — вся главная

Собранная главная находится в `index.html`. Для последовательного просмотра всех экранов откройте `review/index.html`: там реальные скриншоты каждого блока, переход к HTML-макету и длинное изображение всей страницы. Галерея концепций также содержит ссылку на этот просмотр.

Порядок: первый экран → новости → о храме → святыни → приходская жизнь → контакты/карта → подвал. На мобильных блоки складываются вертикально. Внутренние страницы и публикация не включены в эту сборку; фото и неподтверждённые материалы остаются демонстрационными.
