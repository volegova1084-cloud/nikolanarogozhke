# Редизайн сайта Никольского храма — стартовый пакет

Это **стартовые спецификации**, а не готовый сайт. Главный документ запуска: [`MASTER_PROMPT.md`](MASTER_PROMPT.md). Перед началом работы Codex должен прочитать [`AGENTS.md`](AGENTS.md) и материалы в [`specs/`](specs/).

## Как начать
1. Создайте или откройте нужный GitHub-репозиторий в браузерном Codex.
2. Поместите содержимое стартового архива в корень репозитория (можно сделать первый коммит).
3. В новом задании Codex вставьте содержимое `MASTER_PROMPT.md` либо скажите: «Выполни задачу из `MASTER_PROMPT.md`, предварительно прочитав `AGENTS.md` и `specs/*`. Остановись после трёх концепций и галереи для моего выбора».
4. Codex проведёт исследование и создаст прототипы. Одобренная версия впоследствии может быть опубликована на GitHub Pages.

## GitHub Pages
Не включать публикацию до утверждения. Для режима публикации из выбранной ветки убедитесь, что в **публикуемой папке** лежит стартовая страница `index.html` (можно сделать её галереей с ссылками на `concepts/`). Если корень публикуемого сайта отличается от корня репозитория, исправьте относительные пути. Вариант через GitHub Actions также возможен, но не необходим для сайта без сборки. Черновую ветку не публиковать. GitHub Pages может сделать материалы общедоступными; перед публикацией проверьте права на фотографии и персональные сведения.

## Статус
В архиве намеренно нет имитации готовых HTML-концепций, «сделанных скриншотов» или неподтверждённых фотографий: их Codex должен создать после настоящего исследования.
