### Окружение и реальные проверки

Browser-плагин со skill `browser` отсутствует, поэтому использован Playwright из предустановленного runtime. Обычный Chromium не запускался из-за запрета UNIX-сокета process singleton; автоматическое скачивание браузера вернуло некорректный архив. Рабочая проверка: официальный Chrome Headless Shell 131.0.6778.204, `--single-process --no-zygote`, Playwright, локальный HTTP-сервер в одном процессе orchestration. Ни проектный npm, ни сборка, ни новые зависимости проекта не вводились. Cloud Browser не допускает file URL; такой путь не использовался для обхода ограничения. Удалённый браузер открыл действующий сайт и показал его меню/исторический текст, но не использовался для локального QA.

Удалённая визуальная проверка 8 референсов в headless-окружении остановлена `ERR_CERT_AUTHORITY_INVALID` (через сетевой proxy); сертификаты не обходились. Текстовая матрица доступна, desktop/mobile референсов остаются визуально непроверенными. Web и прямой HTTP взаимно дополнили доступность. Это ограничение исследования, не утверждение о недоступности сайтов пользователю.
