# Дизайн-спецификация — исходная версия

> Статус: **утверждённые принципы + предварительные численные ориентиры**. После исследования Codex дополняет и уточняет этот документ; это подробный **справочник**, а не фиксированная пиксельная копия. Для трёх концепций допускаются разные композиции в общих рамках.

## Художественная концепция
Современная православная эстетика: спокойная, сдержанная, светлая, современная, но связанная с архитектурой и духовной историей Никольского храма. Не премиум ради премиальности, не имитация древнерусского оформления, не шаблонная «церковная» графика. Баланс функциональности и выразительных фотографий. Достаточно белого поля и ясной иерархии.

## Предварительная палитра
- Основной фон `#FFFFFF`.
- Вторичный светлый фон `#F5F6F2`.
- Хвойный зелёный `#25483E` для акцентов и ведущих кнопок.
- Тёмный зелёный `#18352E` для контрастных фрагментов.
- Приглушённое золото `#B79C65` — тонкие линии, небольшой орнамент, микроакценты.
- Основной текст: подобрать контрастный нейтральный тёмный тон по результатам тестирования (не делать основной массив текста бледно-зелёным).
Не увеличивать долю декоративного золота; не использовать пёструю цветовую схему. Реальные токены и роли утвердить в CSS-переменных.

## Типографика
Заголовки — кириллический антиквенный шрифт с засечками, исследовать `Prata` / `Cormorant Garamond`; основной текст и UI — `Golos Text` / `Manrope` либо подобные проверенные шрифты с кириллицей. Зафиксировать выбор, лицензии, fallback. Типографическая шкала адаптивная (`clamp()` по ситуации), чёткая иерархия H1/H2/H3, комфортный line-height и длина строки.

## Сетка и ритм
Bootstrap 5.3.x, стандартная 12-колоночная сетка. Текст и карточки в `.container` (до 1320 px на XXL); фоновые/декоративные секции могут идти на всю ширину viewport. Десктоп 1440+, ноутбук 1024–1439, планшет 768–1023, мобильный 320–767. Базовые Bootstrap breakpoint-правила при необходимости дополнять явными media queries. Вертикальная плотность сбалансированная: ориентиры для секций desktop 80–100 px, tablet 48–64 px, mobile 40–48 px; gap карточек 24–32 px, padding 24–32 px. Не вводить жёсткие значения там, где они портят адаптивность.

## Шапка
Два ряда: topbar — подтверждённые контактные сведения и ссылка на расписание; main nav — логотип/название, разделы меню, кнопка «Подать записку». Брендинг в две строки: «Храм святителя Николая» / «на Рогожском кладбище». Знак — простой SVG-силуэт по реальной архитектуре храма, без претензии на официальный утверждённый логотип. Мобильная навигация ясная и доступная.

## Первый экран
Текст слева; фотография храма справа, крупно, с деликатным архитектурным контуром/геометрической маской. Вариативность внутри трёх концепций: пропорции колонок, арочное обрамление, оформление узора. Крупный заголовок с засечками, лаконичное приветствие. Главная кнопка «Расписание богослужений» (хвойный), вторичная «Подать записку» (контур), ссылка «Контакты» (текст/стрелка). На мобильных фото не должно деформироваться, быстрые действия остаются очевидными.

## Секции
- Новости: три новости на главной, фотографии/даты/анонсы. Категории на внутренней странице.
- О храме: реальное фото и краткое исторически достоверное знакомство, переход к подробному материалу.
- Святыни: 2–3 выразительные карточки, далее каталог.
- Приходская жизнь: крупная фотоподача + аннотация, далее направления/галереи.
- Контакты: двухколоночная композиция «данные слева / карта справа», mobile — вертикально; карта Яндекс при разрешённом встраивании.
- Footer: спокойный, компактный, навигация/контакты/официальное название.

## Компоненты
Сначала базовые Bootstrap-компоненты с умеренными модификациями. Описывать все состояния: hover, focus-visible, active, disabled, раскрытое меню; контраст и доступность. Без искусственной сложной библиотечной системы. Декор — архитектурная геометрия (арки, окна, своды) + очень тонкий православный орнамент. SVG без сложных градиентов и тяжёлых паттернов.

## Изображения
Настоящие фотографии **именно данного** храма на первом экране; никакого случайного собора. Изображения локально, источники и права в `assets.md`, WebP и запасной формат при необходимости, адаптивная загрузка и кадрирование с `object-fit`; hero priority, ниже экрана lazy. Никаких случайных иконографических фотографий в карточках святынь; сомнительные изображения заменить явно помеченными заглушками.

## Движение, доступность, контроль
Минимальные hover-переходы 150–250ms; без параллакса; `prefers-reduced-motion`. Семантика HTML5, один H1, клавиатурная навигация, фокус, контраст с ориентиром WCAG 2.2 AA, масштабирование, без отдельного режима для слабовидящих. Проверить 1440/1024/768/375/320 px, отсутствие наложений и горизонтального overflow.
