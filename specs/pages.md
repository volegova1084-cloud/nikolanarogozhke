# Карта страниц и будущих шаблонов

**Фаза 1 — три полноразмерные главные:** каждый вариант содержит hero, новости, о храме, святыни, приходскую жизнь, контакты/карту, footer и двухуровневую шапку.

**Фаза 2 — только после утверждения концепции:**

| Страница | Блоки | Примечание |
|---|---|---|
| Расписание | заголовок, даты, службы/время, пояснения | отдельная страница; данные не выдумывать |
| Подать записку | краткое объяснение, о здравии/упокоении, имена, кнопка | демонстрационная форма без отправки |
| Новости | категории, фильтр, карточки, архив | категории предварительные |
| Публикация | заголовок, дата, категория, текст, медиа | типовой шаблон |
| О храме | история, фотографии, подразделы | использовать проверенные материалы |
| Святыни | каталог карточек | названия и изображения достоверные |
| Отдельная святыня | история и фото | никаких вымышленных описаний |
| Приходская жизнь | направления, события, галереи | только реальные сведения |
| Галерея | сетка фото, увеличенный просмотр | доступные подписи |
| Контакты | адрес, телефон, часы работы, карта, маршрут | информация проверяется |
| Универсальная текстовая | хлебные крошки, заголовок, текст | система шаблонов |

Главная не должна содержать самостоятельный большой раздел расписания: переход только через шапку и hero.

## До утверждения
Для будущих разделов используются кнопки с data-page/data-path и диалог статуса. Это не рабочие формы и не реализованные внутренние страницы. Разделы главной доступны якорями; контакты также в hero. Галерея позволяет открыть каждую концепцию, переключить ширину встроенного предпросмотра.

## Дополнение структуры — 2026-10-08
Будущие страницы: «Духовенство» (pages/clergy.html) и «Духовное образование» (pages/education.html). Материалы и персоналии ожидают проверки. На текущем этапе только пункты меню с честным уведомлением о статусе, внутренние страницы не создаются.

## Главная на согласование
Полная выбранная главная: index.html. Структурный просмотр её блоков: review/index.html. Это семь последовательных экранов одной страницы, а не комплект внутренних страниц.

## Направления прихода — 2026-10-08
Главная содержит переходы: Жизнь прихода (pages/community.html), Воскресная школа (pages/sunday-school.html), Детские кружки (pages/children-activities.html), Занятия для взрослых (pages/adult-classes.html). До разработки внутренних страниц переходы показывают существующий диалог статуса. Названия направлений заданы пользователем; содержание ещё требуется.
