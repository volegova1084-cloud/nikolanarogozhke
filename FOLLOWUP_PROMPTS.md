# Короткие команды для дальнейшей работы с Codex

## Продолжить работу
Прочитай `AGENTS.md`, актуальные `specs/*` и git status. Продолжи с ближайшего незаконченного пункта `specs/progress.md`, сохраняя утверждённые решения. После работы обнови журнал и проверь результат.

## Сравнить три концепции
Проверь `concepts/concept-01.html`—`03.html` на 1440/1024/768/375/320 px и страницу `concepts/index.html`. Подготовь краткое сравнение трёх концепций с плюсами, рисками и рекомендацией, не выбирая за меня окончательный вариант.

## Выбрать и объединить элементы
Основная концепция: [НОМЕР]. Перенеси следующие элементы: [ЭЛЕМЕНТ/ИСТОЧНИК]. Сначала опиши план объединения и актуализируй `specs/design.md`; затем реализуй утверждённую главную, протестируй адаптивность и обнови `progress.md`.

## Разработать внутреннюю страницу
Создай страницу [НАЗВАНИЕ] на основе утверждённой главной, `specs/design.md` и `specs/pages.md`; HTML5, локальный Bootstrap 5.3.x, CSS и vanilla JS. Без PHP. Используй проверенный контент, заглушки помечай. Проверь адаптивность и обнови `progress.md`.

## Изменить компонент
Измени [КОМПОНЕНТ] следующим образом: [ИЗМЕНЕНИЕ]. Сохрани стилистическую целостность, не ломай другие страницы; при необходимости дополни `design.md`, выполни проверки, обнови `progress.md`.

## Подготовить публикацию
Подготовь к публикации на GitHub Pages только одобренную версию: проверь лицензию изображений, наличие index.html в публикуемом корне, относительные пути, CSS/JS и адаптивность. Не включай GitHub Pages и не публикуй без моего отдельного подтверждения.
